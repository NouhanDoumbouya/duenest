# DueNest — Messaging Guide

Use this guide for consistent product, landing, and outreach messaging. Pair it
with [brand-strategy.md](brand-strategy.md) and [voice-and-tone.md](voice-and-tone.md).

## Core messages

- **Product one-liner:** DueNest is where important documents become ready.
- **Expanded:** DueNest helps you organize, prepare, track, generate, and safely
  share important documents before deadlines, applications, renewals, and
  emergencies.
- **Short pitch:** Your important documents are scattered when you need them
  most. DueNest brings them into one private workspace — scan, organize, prepare,
  track deadlines, build application packs, and share safely.

## Feature language (canonical names)

| Use this | For |
|---|---|
| **Vault** | Secure home for important documents |
| **File Inbox** | New scans/uploads waiting to be organized |
| **Scan** | Capture a document with the camera |
| **Document Tools** | Prepare, convert, compress, watermark, fill, sign, export |
| **Convert & Export** | Format/size changes and print-ready output |
| **Fill & Sign** | Add fields, signature image, date/initials (not legal e-sign) |
| **Deadlines & Renewals** | Expiry dates, deadlines, renewals, reminders |
| **Application Packs** | Complete document sets for a purpose |
| **SafeSend** | Secure sharing with expiry, access rules, revocation |
| **Custom QR** | Branded QR for a SafeSend link |
| **Emergency Access** | Critical documents for trusted people |
| **AI Assistant** | Review-first AI for documents |
| **Smart Intake** | AI suggestions for type/category/dates/reminders |
| **Chat with Documents** | Ask questions grounded in selected documents |
| **Document Generation** | Draft CVs, cover letters, application letters |
| **Document Requests** | Request missing documents via secure upload links |
| **DueNest Portals** | Org workspaces to collect/review/track submissions |

**Avoid:** "Documents" as the main nav name, Subscriptions, Finance, Budgeting,
Spending, "Random AI", "generic files/storage".

## Segment messages

See [brand-strategy.md](brand-strategy.md) for pillars. Each segment: pain →
promise → key features → CTA.

- **Students:** Scattered academic/visa/scholarship/job documents → keep them
  ready → Vault, Scan, Application Packs, Deadlines, Document Generation,
  SafeSend → *Start organizing for free*.
- **International students / migrants:** Documents across countries and formats →
  one private, ready place → Vault, Smart Intake, Packs, Emergency Access → *Build
  your Vault*.
- **Scholarship applicants:** Incomplete, last-minute packs → prepare a complete
  scholarship pack → Scholarship pack, checklist, Document Generation, deadlines →
  *Create an application pack*.
- **Visa applicants:** Missing/expired documents delay applications → prepare and
  track visa documents → Visa pack, passport reminders, Fill & Sign, SafeSend, QR
  → *Prepare a visa pack*.
- **Job applicants:** Each role needs tailored CV + letters + certificates →
  build a job pack → Job pack, CV/cover-letter drafts, deadlines, export/share →
  *Create a job pack*.
- **Families:** Everyone's critical documents, findable in emergencies → Vault +
  Emergency Access → trusted, read-only access → *Set up emergency access*.
- **Agencies / schools / HR / NGOs:** Collecting documents from many people is
  chaotic → request, review, track, and safely manage submissions → DueNest
  Portals, Document Requests, checklists, reminders → *Create a portal*.

## Claims policy

Only state what the implementation supports. Never claim legal e-signature
validity, official application requirements, or security certifications that are
not real. Templates are generic and editable — always: "Requirements vary.
Verify with the official source."
