# DueNest Brand Assets

This folder contains the official brand assets for DueNest.

**DueNest is a private life-document readiness platform** — it helps people and
organizations store, scan, organize, prepare, track, generate, understand,
request, fill/sign, and safely share important documents before deadlines,
applications, renewals, and emergencies.

> **Brand sentence:** DueNest is where important documents become ready.

DueNest is *not* a generic cloud drive, a subscription tracker, a finance app, or
a random AI chatbot. AI is one review-first assistant inside the workflow, never
the headline.
