# CertaNest — Microcopy Patterns

> Aligns with `brand/voice-and-tone.md` and `brand/messaging-guide.md`. Voice: calm,
> precise, trustworthy, human, practical. This is the reusable copy library.

## Voice in one line

Say what will happen, in plain words, without hype or fear.

## Button verbs (canonical)

Use specific verbs, never "Submit" / "Click here" / "Learn more" everywhere.

| Action | Label |
| --- | --- |
| Scan | **Scan document** |
| Upload | **Upload file** |
| Create pack | **Create pack** |
| Attach existing | **Attach from Vault** |
| Add deadline | **Add deadline** |
| Share | **Share safely** |
| Save processed output | **Save prepared copy** |
| Review AI output | **Review suggestion** |
| Delete (reversible) | **Move to Trash** |
| Restore | **Restore document** |
| Revoke a link | **Revoke link** |
| Generate draft | **Generate draft** |
| Ask AI about a doc | **Ask this document** |

## Trust notes (reusable lines)

- **Private until shared.** No public link without your confirmation.
- **Original preserved.** We'll save a prepared copy.
- **Removed from pack. File not deleted.**
- **Moved to Trash. You can restore it.**
- **No public link has been created yet.**
- **You can revoke this link at any time.**
- **This QR follows your SafeSend access rules.**
- **Scans stay private unless you share them.**
- **AI helps you prepare. You stay in control.**
- **Review before sharing or submitting.**

## Honest warnings (never overclaim)

- PDF→Word: *Some formatting may change. Review before submitting.*
- Fill & Sign: *This prepares a signed copy. Legal acceptance may depend on the recipient
  and jurisdiction.*
- Templates: *Requirements vary. Always verify with the official source.*
- AI: *AI can make mistakes. Review important details.*
- Blurry scan: *This scan looks blurry. Rescan for a clearer copy?*

## Banned language (see brand honesty guardrails)

`guaranteed`, `legally binding`, `official requirements`, `100% ATS`, `SOC 2`, `HIPAA`,
`GDPR-compliant`, `end-to-end encryption`, `trusted by thousands`, `magic AI`, `unlimited`,
fake testimonials/numbers/awards — unless actually implemented and verified.
Subscription/budget/finance framing is banned except truthful "recurring reminder"
language under Deadlines & Renewals.

## Empty-state pattern

`Title (calm fact) → one sentence of what appears here → one primary CTA.`

| Module | Title | Body | CTA |
| --- | --- | --- | --- |
| Vault | Your Vault is empty. | Start with one important document. | Scan document / Upload file |
| File Inbox | File Inbox is clear. | New scans and uploads appear here before you organize them. | — |
| Bundles | No application packs yet. | Prepare documents for a visa, scholarship, job, university, travel, or custom need. | Create pack |
| Deadlines | No deadlines yet. | Add expiry dates and renewals so CertaNest can remind you. | Add deadline |
| Quick Share | No shared documents yet. | Share sensitive documents with expiry, access control, and QR. | Share safely |
| AI | Ask about a selected document or generate a draft. | — | Select a document |
| Emergency | No emergency pack yet. | Prepare critical documents for trusted access. | Create emergency pack |
| Requests | No requests yet. | Request missing documents without messy back-and-forth. | New request |

## Error pattern

`What happened (plain) → why if useful → how to recover (action).` Never a dead end.
Example: *"Upload didn't finish. Check your connection and try again." [Retry]*

## Success pattern

Quiet confirmation + the next useful action. Example after a pack hits 100%:
*"This pack is ready."* with **Share safely** / **Generate cover sheet**.

## Status labels (pair with status color map)

Ready · Expiring soon · Overdue · Shared · Revoked · Expired · Draft · Needs review ·
Prepared copy · Original · In N packs · Private.
